# ⚔️ Эпическая битва (Epic Battle)

Добро пожаловать в проект вашей первой игры на C# в VS Code!

«Эпическая битва» — это бесконечный пошаговый рогалик-таймкиллер, в котором ваш герой (Воин) сражается с бесконечными волнами Орков, становится сильнее с каждым уровнем и сталкивается со случайными событиями.

Проект разработан с использованием **WPF (Windows Presentation Foundation)**, что позволяет создавать красивый современный интерфейс с плавной анимацией на Windows.

---

## 📜 Краткое техническое задание (GDD)

### 1. Основная концепция
- **Жанр:** Пошаговая дуэль, Рогалик (Roguelike), Таймкиллер.
- **Платформа:** Windows (WPF, .NET 8).
- **Цель игры:** Пройти как можно больше уровней (Орков), выживая и грамотно комбинируя прокачку, магию и зелья.
- **Цикл игры:**
  1. Случайное событие (опционально) -> 2. Бой с Орком -> 3. Экран победы (выбор награды) -> Возврат к п.1.

### 2. Интерфейс (UI)
- **Окно:** 800×600, стильная тёмная тема.
- **Показатели (Бар-статусы):**
  - Полоски HP (Здоровье) и MP (Мана) в процентах и абсолютных числах для Игрока.
  - Полоска HP для Орка.
  - Индикаторы количества зелий (Здоровья и Маны).
- **Лог событий:** Скроллируемое текстовое поле посередине, где описывается всё происходящее ("Орк наносит 15 урона", "Вы выпиваете зелье").
- **Кнопки действий (блокируются во время хода врага):**
  - ⚔️ **Удар** — базовая атака мечом.
  - 🛡 **Защита** — снижает получаемый в этом ходу урон на 50%.
  - ✨ **Магия** — мощная атака (например, Огненный шар), которая наносит больше урона, но тратит MP.
  - 🧪 **Зелье Здоровья** — восстанавливает часть HP.
  - 💧 **Зелье Маны** — восстанавливает часть MP.
- **Строка статуса:** Подсказки для игрока ("Ваш ход!", "Орк готовится к атаке...").

### 3. Игровые механики
- **Восстановление:** В начале каждого нового уровня HP и MP героя восстанавливаются на 100%.
- **Система зелий (Эстус):** Заряды зелий ограничены (например, со старта 3 здоровья и 2 маны). Сами по себе они не восстанавливаются после боя.
- **Прокачка (Рогалик):** После убийства Орка открывается окно выбора из 3-х случайных карточек. Примеры:
  - Увеличить базовый урон мечом.
  - Увеличить максимальное здоровье на 20.
  - Пополнить все заряды зелий (вместо усиления статов).
  - Изучить усиленную магию.
- **Масштабирование сложности:** С каждым уровнем Орки получают больше HP, бьют больнее, а иногда получают случайные свойства (например, "Орк-берсерк" или "Бронированный орк").
- **Случайные события (Random Encounters):** Перед боем может произойти текстовое событие. Пример: *"Вы находите у костра старого торговца. Он предлагает вам выпить странный отвар. Согласиться? (50% шанс получить +10 к урону, 50% шанс потерять 20% HP)"*.

### 4. Визуал и Звук (Планы на будущее)
- **Анимации:** Тряска экрана при получении урона, вспышки при магии, анимация удара (WPF Storyboard).
- **Звук:** Использование `SoundPlayer` или `MediaPlayer` для звуков ударов, блокировки, магии и фоновой эпичной музыки.

## 🛠️ Руководство для новичка: Как запустить игру в VS Code

Поскольку это ваша первая игра, вот пошаговая инструкция, как всё настроить и запустить:

### Шаг 1: Установка необходимых инструментов
1. Скачайте и установите **[.NET 8.0 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)** (выберите установщик для Windows x64). Это "движок", который понимает язык C#.
2. Откройте **VS Code**.
3. Перейдите во вкладку **Extensions** (Расширения) слева (или нажмите `Ctrl+Shift+X`).
4. Найдите и установите официальное расширение **C# Dev Kit** (от Microsoft).

### Шаг 2: Структура проекта
В этой папке вы найдете следующие файлы:
- `EpicBattle.csproj` — файл настроек проекта (указывает, что это WPF приложение на .NET 8).
- `App.xaml` и `App.xaml.cs` — стартовые файлы приложения.
- `MainWindow.xaml` — визуальная разметка интерфейса (кнопки, полоски здоровья).
- `MainWindow.xaml.cs` — вся логика игры (удары, расчеты, прокачка).

### Шаг 3: Как запустить игру
1. Откройте папку с проектом в VS Code (`File -> Open Folder...`).
2. Откройте терминал в VS Code: в верхнем меню выберите `Terminal -> New Terminal`.
3. Введите команду:
   ```bash
   dotnet run
   ```
4. Нажмите **Enter**. Проект скомпилируется, и перед вами откроется окно вашей игры!

> **Совет:** Чтобы пересобрать проект после изменения кода, просто сохраните файл (`Ctrl+S`) и снова запустите `dotnet run`.
